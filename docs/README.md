# Documentation

## Overview

This document provides an overview of the chamego library.

## API Reference

### core Package

- `New(name, version string) *chamego` - Creates a new chamego instance.
- `Info() string` - Returns information about the library.

### utils Package

- `Format(s string, padding int) string` - Formats a string with padding.
- `Join(sep string, items []string) string` - Joins strings with a separator.
